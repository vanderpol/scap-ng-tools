# Full pinned OVAL Test Content: independent source-to-native parity gate

**Status: review-only audit, not a claim of completed conversion or scanner equivalence.**

The original `OVAL-Community/SCAP-Self-Assertion` at
`e3538595c5083b9c34d937a81d319234df9bbfaa` has **144 standalone
XML files** across 13 platform directories under
`SCAP_1.4/OVAL_Test_Content` (plus supporting archives). The older
`scap-ng-tools` PR #53 publication covers only
`agnostic, unix, linux`: 76 Definitions / 462 Tests, of which only
9 Definitions / 76 Tests were converted. **Do not interpret those figures
as coverage of the entire original tree.**

This script independently reads the **pinned original XML**, not the
converter's reported source list, and compares it with a produced native
package. It is usable with the old package to expose missing source areas,
and with a new full-tree package from the latest converter.

## Reproducible use

```bash
# In a separate verified OVAL-Community/SCAP-Self-Assertion Git checkout:
git rev-parse HEAD  # MUST equal e3538595c5083b9c34d937a81d319234df9bbfaa
git status --short -- SCAP_1.4/OVAL_Test_Content  # MUST be empty

python3 scripts/audit_self_assertion_parity.py \
  --source-root /checkout/SCAP-Self-Assertion/SCAP_1.4/OVAL_Test_Content \
  --pack /output/latest-full-tree-native \
  --expected-xml 144 \
  --output /tmp/full-oval-test-content-parity.json

# Approval gate: fails nonzero on missing/blocked source coverage or mismatch.
python3 scripts/audit_self_assertion_parity.py \
  --source-root /checkout/SCAP-Self-Assertion/SCAP_1.4/OVAL_Test_Content \
  --pack /output/latest-full-tree-native \
  --expected-xml 144 \
  --require-full \
  --output /tmp/full-oval-test-content-parity-strict.json

python3 -m unittest discover -s tests -p test_self_assertion_parity.py -v
```

The source checkout verification is mandatory in ordinary CLI operation;
`--allow-unverified-fixture-source` exists only for synthetic test data.
All source paths, Test/Variable IDs, and converter artifacts are tied to
SHA-256 and exact original Git commit.

## Gates

1. **Entire source inventory** — every original XML and OVAL Definition,
   supporting ZIP/TAR content, source identity, and Test graph counted;
   duplicates and unexpected/unclassified archive formats are reported.
2. **Exhaustive accounting** — every original Definition has exactly one
   converter status and source-backed diagnostic if blocked; unlisted
   Definitions are explicit failures.
3. **Independent structural parity of converted cases** — native identity
   and source-trace bindings, all referenced Tests, exact generated bytes,
   original Variable literal values, order/duplicates, types, aliases,
   Evaluate Boolean structure, and supported check/existence cardinalities.
   Complex/inactive Variable transformations fail closed until their
   recursive semantics are independently compared.
4. **Schema/authoring** — separately run canonical JSON/YAML validation,
   semantic-pack verification, deterministic rebuild and filename
   discovery tests; this audit alone does not provide these tests.
5. **Execution/SCC equivalence** — separately run RI on generated
   Assessments, original SCC on the same controlled conditions and
   compare results/statuses. Even complete structural parity is
   **not** equivalent to runtime qualification.

The report's `runtime_equivalence_proved` is unconditionally **false**.
A structurally complete report must not be described as full semantic
equivalence.

## Platform dispositions

All 144 XML files are within source accounting. Whether to convert a
particular OS/platform depends on approved 0.4 capability scope. A
platform that is intentionally not implemented (e.g., legacy/retired)
still needs a source-linked blocked/excluded row and recorded owner
decision; no platform is silently omitted from the denominator.

Source accounting and independent parity are separate from the
historical 65-benchmark corpus (`vanderpol/scap-ng-tools` PR #33),
which reports **Rules**, not Self-Assertion Definitions. They cannot
be substituted for one another.
